To compile and optimize the entire website for production deployment:


## 🔧 How to Fix Common Errors

1. **Port 3000 already in use:**
   - If port 3000 is occupied by another process, Vite will automatically select the next free port (e.g. `http://localhost:3001/`). You can also specify a custom port in `vite.config.js`:
     ```js
     server: { port: 5173, open: true }
     ```

2. **Node version compatibility:**
   - Ensure you are running Node.js version 18.0.0 or higher:
     ```bash
     node -v
     ```

3. **WebGL context loss / low battery mode:**
   - The 3D components automatically fall back gracefully on devices that do not support WebGL or have high hardware restrictions.

## 🚀 How to Deploy Using Vercel (Recommended)

### Method A: One-Click Web Deployment
1. Go to [vercel.com](https://vercel.com) and log in with GitHub.
2. Click **Add New Project** and select `satarupa-portfolio`.
3. Framework Preset: **Vite**
4. Root Directory: `./`
5. Click **Deploy**. Vercel will automatically build and assign a free HTTPS URL (e.g. `satarupa-dutta.vercel.app`).

### Method B: Vercel CLI
```bash
npm install -g vercel
vercel
```

---

## 🚀 How to Deploy Using Netlify

### Method A: One-Click Web Deployment
1. Go to [netlify.com](https://netlify.com) and log in with GitHub.
2. Click **Add new site** > **Import an existing project**.
3. Select your `satarupa-portfolio` repository.
4. Settings:
   - **Build command:** `npm run build`
   - **Publish directory:** `dist`
5. Click **Deploy Site**.

### Method B: Netlify CLI
```bash
npm install -g netlify-cli
netlify deploy --prod --dir=dist
```
